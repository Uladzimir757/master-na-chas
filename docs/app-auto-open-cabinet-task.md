# Задание: приложение сразу открывает кабинет мастера, если вход уже сохранён

Голосовое обсуждение 04.11.2026. Сейчас приложение одно (Capacitor-обёртка
над сайтом), общее для мастера и клиента. У клиента аккаунта нет вовсе
(управление записью — по ссылке из SMS). У мастера — вход по токену,
который должен сохраняться на устройстве, но при каждом открытии
приложения мастер всё равно сначала попадает на главную (публичная
страница выбора мастера для клиента) и оттуда сам переходит в кабинет —
лишний шаг при каждом запуске.

## Что сделать

1. При запуске приложения (и сайта в браузере на этом устройстве) —
   проверить, есть ли сохранённый токен мастера. Если есть и он валиден —
   сразу открывать `/cabinet/`, минуя главную страницу выбора мастера.
2. Если токена нет — обычное поведение, клиент видит главную как сейчас.
3. Токен живёт на устройстве до явного нажатия «Выход» в кабинете — не
   сбрасывать его автоматически при обычном закрытии/перезапуске
   приложения.
4. Если сервер отклоняет токен как просроченный/недействительный (401 на
   защищённом эндпоинте кабинета) — сбросить сохранённый токен и вернуть
   на форму входа, а не оставлять в петле ошибок.

## Не входит в эту задачу

- Разделение на два отдельных нативных приложения (мастер/клиент) —
  отдельная, более крупная задача, обсуждалась отдельно, не делать сейчас.
- Экран выбора «Я мастер» / «Я клиент» — рассматривался как альтернатива,
  отклонён в пользу автоматического определения по сохранённому токену.

## Как проверить

На эмуляторе и на живом телефоне:
1. Войти в кабинет мастера → закрыть приложение полностью → открыть снова
   → должен открыться кабинет, не главная.
2. Нажать «Выход» → закрыть и открыть приложение → должна открыться
   главная (выбор мастера для клиента), не кабинет.
3. (Если просимулировать просроченный токен) — открыть приложение с
   невалидным сохранённым токеном → должна открыться форма входа, не
   бесконечная загрузка/ошибка.
