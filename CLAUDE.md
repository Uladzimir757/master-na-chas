# CLAUDE.md — master-na-chas (Złota Rączka / «Мастер на час»)

Контекст для ЛЮБОЙ сессии Claude Code с этим репо — из чата, из терминала,
параллельной сессии. Мост между кодом и чатами: что узнала одна сессия,
должно быть видно следующей через этот файл. Обновляй его короткими
правками по ходу работы, не жди отдельного запроса.

## Что это

Своя букинг-платформа для «мастер на час» (2 мастера, Trójmiasto) — слоты и
календарь, а НЕ лид-маркетплейс (не как Fixly.pl). Отдельный продукт/бизнес
от [[zlecai]] (dispatcher) — тот универсальный AI-диспетчер лидов, ЭТОТ
проект — конкретная букинг-система с собственными мастерами и клиентами.
Спроектирован так, чтобы движок позже переиспользовался в Garage System при
необходимости: сущности (`tenant`/`provider`/`service`/`booking`) одинаковы,
разница в данных, не в коде. Отдельный репозиторий намеренно — см.
`docs/decisions.md`, не склеивать без явного решения.

## Стек и ключевые ID

- Backend: FastAPI (Python) + SQLAlchemy 2.0 async, `app/main.py`.
- БД: Postgres, схема в `db/schema.sql` (EXCLUDE constraint против двойного
  бронирования, btree_gist — подтверждено рабочим тестом, не заглушка).

## Структура (см. README.md для деталей)

- `app/slot_engine.py` — доступность/слоты, таймзона Europe/Warsaw.
- `app/notifications.py` — Telegram + Web Push мастеру, SMS (Twilio)
  клиенту; best-effort, не роняют запрос при сбое.
- `app/security.py` — сессионная авторизация мастера (cookie, не JWT —
  намеренно минимально для 2 пользователей, см. `docs/mvp-task.md` #4).
- Регистрация мастеров только через суперадмина (`X-Admin-Secret`), без
  публичной формы.
- `scripts/seed.py` — тенант + стартовая услуга + 2 мастера + рабочие часы.
- `app/confirm_timer.py` — таймер подтверждения заказа (15 мин, напоминания
  на 5/10-й, автоотмена). Истечение ленивое (перед слотами/календарём/бронью),
  напоминания — `POST /internal/tick` (`X-Tick-Secret`, env `TICK_SECRET`):
  API на free tier Render, Cron Job там нет — тик дёргает внешний пингер.
- Города: `city`/`provider_city`, клиент выбирает город первым шагом
  (`docs/confirm-timer-travel-cities-task.md`).

## Процесс

- У агента нет git credential helper на бридже — `git push` отсюда не
  проходит. Коммит локально → пользователь пушит из своего терминала.
- Перед push — `git pull --rebase origin main` (не слепой force), если
  параллельно могла идти другая сессия/ветка.
- Тесты: см. `tests/README.md` — как поднять тестовый Postgres и прогнать
  pytest (нужен реальный Postgres, не просто fake-conn, из-за
  EXCLUDE-констрейнта).
